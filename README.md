# goamqp — retired

> [!IMPORTANT]
> This repository is archived and no longer maintained.
> Development continues on Codeberg as
> **[codeberg.org/messaging/go-messaging-amqp](https://codeberg.org/messaging/go-messaging-amqp)**.

The successor is the AMQP/RabbitMQ transport of the
[messaging](https://codeberg.org/messaging/messaging) project, a multi-transport
messaging library with a shared spec, TCK and topology tooling.

It is not a drop-in replacement: the module path and API have changed.

```sh
go get codeberg.org/messaging/go-messaging-amqp
```

Existing versions of `github.com/sparetimecoders/goamqp` remain available through
the Go module proxy.
